# Agent Guidelines

## Goal

This repository is a Kuzzle application template built in TypeScript and shipped as ESM.

## Runtime Rules

- Use ESM-compatible imports in source files.
- Always include the `.js` extension in internal imports.
- Prefer relative imports over TypeScript path aliases unless a runtime resolver is explicitly configured.
- Keep the build output runnable with plain `node`.
- The active dev loop uses `tsx watch app.ts`.

## Project Structure

- `app.ts` is the application entry point.
- `lib/` contains the application code.
- `dist/` is generated by `tsc`.
- `Dockerfile` builds a production image from the compiled output.
- `docker-compose.yml` runs the app in dev mode through `npm run dev`.

## TypeScript Conventions

- Target Node ESM semantics.
- Keep compiler settings aligned with Node's module resolution.
- Avoid imports that only work in TypeScript but fail in emitted JavaScript.
- `tsc --build tsconfig.json` is the authoritative build command.

## Docker Conventions

- Local compose should use `npm run dev` only.
- Production containers should still start from the compiled application entry point.

## Editing Rules

- Keep changes minimal and aligned with the existing template style.
- Update the README when the startup or build flow changes.
- Verify the build after touching module resolution, package metadata, or Docker startup commands.
- Update this file when the dev loop, Docker entrypoint, or module-resolution rules change.
